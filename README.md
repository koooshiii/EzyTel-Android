# EzyTel — پروژه‌ی اندروید

همان فایل `index.html` برنامه (بدون هیچ تغییری) داخل یک پوسته‌ی WebView اندروید قرار گرفته است:
`app/src/main/assets/index.html`

## ساخت APK — روش ۱: بدون نصب هیچ چیز (GitHub Actions)
1. در github.com یک مخزن (repository) خصوصی یا عمومی بسازید.
2. همه‌ی محتوای همین پوشه را در آن آپلود کنید (پوشه‌ی مخفی `.github` هم باید آپلود شود).
3. تب **Actions** ← **Build APK** ← **Run workflow**.
4. بعد از ۳ تا ۵ دقیقه، پایین صفحه‌ی اجرا در بخش **Artifacts** فایل `EzyTel-APK` را دانلود کنید؛ داخلش `app-debug.apk` است.
5. APK را روی گوشی نصب کنید (اجازه‌ی «نصب از منابع ناشناس» لازم است).

## روش ۲: Android Studio
1. Android Studio را نصب کنید، **Open** ← این پوشه.
2. صبر کنید همگام‌سازی Gradle تمام شود.
3. **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**.
4. خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## به‌روزرسانی برنامه
هر وقت `index.html` جدید گرفتید، آن را جایگزین `app/src/main/assets/index.html` کنید و دوباره APK بسازید.
(اگر با همان کلید امضا بسازید و `versionCode` را در `app/build.gradle` بالا ببرید، روی نسخه‌ی قبلی نصب می‌شود و اطلاعات حفظ می‌شود.)

## نسخه‌ی نهایی (Release) برای انتشار
APK آماده فقط با کلید دیباگ امضا شده و برای استفاده‌ی شخصی کافی است. برای انتشار در بازار/مایکت یک keystore بسازید و
در Android Studio: **Build ← Generate Signed Bundle / APK**.

## چه کارهایی پوسته انجام می‌دهد
- اجرای برنامه از آدرس https امن داخلی (برای fetch، IndexedDB، Cache API)
- باز کردن لینک‌ها در مرورگر گوشی
- ذخیره‌ی فایل‌های دانلودی (عکس، ویدیو، صوت، متن) در پوشه‌ی **Downloads**
- پنجره‌های تأیید و پرسش (confirm / prompt) و انتخاب فایل (بازیابی پشتیبان، وارد کردن کانال‌ها)
- ویدیوی تمام‌صفحه، دکمه‌ی برگشت اندروید، رنگ نوار وضعیت هماهنگ با تم برنامه
- حداقل اندروید ۱۰ (API 29)
